Windows "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행. macOS 처음 열 때 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기.

  • 카카오톡을 건드리지 않습니다. 실행 파일 수정이나 코드 주입이 없습니다.
  • 광고 서버에 접속하지 않습니다. 노출·클릭 기록도 보내지 않습니다.
  • 서명을 확인한 업데이트만 설치합니다. 소스는 모두 공개돼 있습니다.
